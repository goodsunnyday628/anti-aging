# Anti-Aging Research

医学科研代码与可复现分析项目起点。

## 研究方向

- 衰老与心血管心律失常
- 免疫衰老与心房重构
- 公共数据库、多组学及临床表型研究

本仓库从零开始搭建。此前其他电脑或账号中的项目**未自动迁移**，后续仅按需引入经过核验、允许共享的材料。

## 工作原则

1. 文献记录 DOI/PMID 和来源；未经核实的论文与结论不得作为已证实证据。
2. 原始数据保留只读副本；代码、衍生数据和输出结果分开管理。
3. 保存可复现代码、依赖版本、分析参数及验证记录。
4. 不提交患者资料、未脱敏影像、账号密钥或其他受限信息。
